# SillyTavern 酒馆项目收藏

适合酒馆插件开发者参考的 GitHub 项目（2026 年 10 月整理）。

| 项目 | 简介 | Stars | 推荐理由 |
|---|---|---|---|
| [st-memory-enhancement](https://github.com/muyoou/st-memory-enhancement) | 酒馆长期记忆增强插件 | 1504 | 酒馆插件里 Stars 最多之一，学习成熟插件怎么组织代码、怎么和酒馆接口交互的最佳范本 |
| [TauriTavern](https://github.com/Darkatse/TauriTavern) | 用 Tauri/Rust 重写的酒馆 | 1875 | 能看到酒馆核心逻辑被完整重写一遍，有助于理解酒馆内部结构，也要留意你的插件在这类分支上的兼容性 |
| [fount](https://github.com/steve02081504/fount) | AI 角色运行时框架 | 691 | 酒馆之外的另一种角色系统设计思路，可以给插件功能找灵感 |
| [rpg-companion-sillytavern](https://github.com/SpicyMarinara/rpg-companion-sillytavern) | 追踪角色、任务、背包的 RPG 扩展 | 320 | 展示了怎么用 AI 生成内容维护游戏状态，做玩法类插件可以直接参考 |
| [SillyTavern-MemoryBooks](https://github.com/aikohanasaki/SillyTavern-MemoryBooks) | 把聊天记忆存进世界书 | 314 | 和 st-memory-enhancement 走的是不同的记忆方案，两个对比着看收获最大 |
| [worldbook-skill](https://github.com/echo-xianyu/worldbook-skill) | 让 Agent 自动写世界书 | 212 | 把 AI Agent 和世界书结合，是酒馆生态的新方向，适合想做自动化工具的开发者 |
